# Repository Guidelines

## Mission

Build a polished Replit preview for **Creator Sponsorship Analyzer**, answering: “What brand exposure did this sponsored video deliver?” Flow: video URL and optional brand → Analyze → synchronized events → exposure summary and creative timeline.

Work autonomously. The repository may be empty; scaffold it in place and leave a working preview. Do not stop after planning.

## Replit Stack and Commands

Use Vite, React, and TypeScript with minimal dependencies.

- `npm install`: install dependencies.
- `npm run dev -- --host 0.0.0.0`: launch the preview; respect Replit's `PORT`.
- `npm run build`: type-check and build production output.

Before finishing, run the build and fix errors. Ignore `node_modules`, `dist`, and local environment files.

## Structure and Architecture

- `src/components/`: player, event feed, timeline, summary cards.
- `src/data/`: realistic example campaign data.
- `src/types/analysis.ts`: stable normalized analysis model.
- `src/services/analysis/`: adapter interface, mock, and Oriane stub.
- `public/`: dependable demo video or poster assets.

UI components consume only a normalized `AnalysisResult`, never Oriane shapes. Include brand, video URL, duration, engagement, events, summary, and creative segments. Events have `type`, `start`, `end`, `label`, and optional `text`. Mark inferred visibility duration as estimated.

## Preview Requirements

Create a responsive, demo-ready single page with:

- A landing state with title, URL input, optional brand input, **Analyze**, and **Try Example Campaign**.
- Analysis with reliable HTML5 demo video left and synchronized feed right.
- Clickable seek events with current-event highlighting.
- A progress timeline with event markers, summary cards, and segments for Hook, Story/context, Brand introduction, Demo, and CTA.
- Mock product, logo, spoken mention, demonstration, and CTA events.
- Loading and invalid-input states, accessible controls, and visible focus styles.

Use premium editorial styling, strong typography, restrained color, generous spacing, subtle motion, and excellent mobile behavior.

## Oriane and Security

Mock the flow first. `analyzeVideo(videoUrl, brand)` returns normalized data asynchronously. Keep `analyzeVideoWithOriane` server-only and stubbed until documented. Read `ORIANE_API_KEY` only from Replit Secrets; never expose or log it. Do not invent fields.

## Scope Limits

Do not build authentication, accounts, payments, creator fee decisions, campaign management, dashboards, benchmarking, scoring algorithms, or a database. Do not depend on TikTok embedding for the demo.

## Quality Bar

Use two-space indentation, `PascalCase` components, `camelCase` functions, and small modules. The task is complete only when the example campaign works end to end in Replit and `npm run build` succeeds.
